Optional WSL2/Linux extra isolation: launch Claude Code from the project root with `claude --settings config/strict-wsl-settings.json` (verify your Claude Code version first). This stricter file requires sandbox support and blocks unsandboxed fallback. These are safety controls, not an absolute security guarantee. Native Windows does **not** support sandboxed Bash; do not pass these extra settings there. Always review permission requests. Empty `allowedDomains` alone is not a hard network deny in every mode: use manual permissions and do not authorize new domains; strict network policy may additionally require a user-level `network.strictAllowlist` setting.
